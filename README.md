# Devil Run

A fast-paced 2D mobile platformer built in Unity, inspired by 
Little Devil Inside.

## Gameplay
- Run through levels filled with moving obstacles and hazards
- Dodge traps, spikes and environmental dangers
- Collect tokens scattered across each level
- Built and optimized for Android mobile

## Features
- Cinemachine camera system for smooth tracking
- Touch-based mobile controls
- Multiple obstacle types (spikes, ground destroyers)
- Token collection system
- Modular level design using Unity Tilemaps
- Multiple zones across 10+ levels

## Built With
- Unity 6
- C#
- Cinemachine
- Unity Tilemap

## Controls
- Touch input (Android)
